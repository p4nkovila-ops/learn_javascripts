# Курс: JavaScript для инди-игр — от нуля до «про»

Это репозиторий моего обучения. Здесь лежит план, правила для учителя (Claude) и записи о том, что у меня получается.

- **`CLAUDE.md`** — правила для Claude: как меня учить. Claude читает его сам в начале каждого чата.
- **`ПЛАН.md`** — карта всего пути: части и этапы по порядку.
- **`план/`** — подробно каждая часть: что понять, что сделать руками, когда этап считается пройденным.
- **`ПРОГРЕСС.md`** — где я сейчас, что получилось, что не получилось, что повторить. Claude обновляет после каждого занятия.
- **`код/`** — всё, что я пишу: упражнения и игры (папка появится на первом занятии).

## Как начать занятие
В новом чате с Claude (в этом репозитории) написать:

```
Продолжаем учёбу. Сделай git pull, прочитай CLAUDE.md, ПЛАН.md и ПРОГРЕСС.md и веди меня дальше с того места, где остановились.
```
