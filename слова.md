# Словарик: английские слова в коде

Имена в коде пишем по-английски (решение ученика 2026-11-16). Здесь — каждое слово, которое встретилось, с переводом. Новое слово — дописывается сюда.

## Команды языка и браузера
| Слово | Читается | Значит |
|---|---|---|
| `console` | консоль | консоль — окно, куда код пишет ответы и ошибки |
| `log` | лог | записать (в журнал) |
| `error` | эррор | ошибка |
| `let` | лет | заведи коробку (переменную), которую можно менять |
| `const` | конст | заведи коробку, которую менять нельзя (от constant — постоянный) |
| `undefined` | андефайнд | не определено, «ничего» |
| `Number` | намбер | число; `Number(...)` превращает текст в число (с большой буквы!) |

## Слова из сообщений об ошибках
| Слово | Значит |
|---|---|
| `SyntaxError` | ошибка записи: браузер не понял, как прочитать |
| `ReferenceError` | нет такого имени |
| `TypeError` | так делать с этой вещью нельзя |
| `Uncaught` | «не поймано» — ошибка остановила скрипт |
| `Unexpected identifier` | неожиданное имя (слово не на своём месте) |
| `is not defined` | не определено, такого нет |
| `has already been declared` | уже заведено |
| `Missing initializer` | не хватает начального значения (`= ...`) |
| `Assignment to constant variable` | попытка положить новое в `const` |
